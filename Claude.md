# Claude.md

## Проект: Telegram-бот для помощи с ПДД

Этот проект направлен на создание полезного телеграм-бота для жителей республики, который помогает быстро и понятно разобраться в правилах дорожного движения.

### Цель проекта
- Сделать ПДД понятными и доступными для широкой аудитории.
- Помогать пользователям быстро находить ответы на частые вопросы.
- Снижать количество ошибок и нарушений за счёт понятных рекомендаций.

### Основная идея
Пользователь пишет вопрос или выбирает тему из меню, а бот отвечает кратко, понятно и по делу. Например: "Что делать на перекрёстке?", "Можно ли парковаться здесь?", "Какой штраф за превышение скорости?"

### Важная особенность проекта
В дальнейшем в бота будет встроен ИИ-агент, который будет помогать пользователям на основе документа с правилами ПДД. Это позволит получать ответы не только из статической базы FAQ, но и из более гибкой системы знаний.

### Целевая аудитория
- Новые водители.
- Пешеходы.
- Водители с небольшим опытом.
- Люди, которым важно быстро получить понятный ответ без сложных юридических формулировок.

### Принципы работы бота
- Простые и понятные ответы.
- Краткость и практическая польза.
- Примеры из реальной жизни.
- Поддержка в формате FAQ и пошаговых инструкций.
- Акцент на безопасность и законность.

### MVP-функции
1. Приветствие и главное меню.
2. Базовые ответы по самым частым вопросам ПДД.
3. Разделы по темам: знаки, скоростной режим, парковка, перекрёстки, пешеходы, штрафы.
4. Кнопки быстрого выбора тем.
5. Возможность задать вопрос в свободной форме.

### Формат ответов
Каждый ответ должен включать:
- короткий прямой ответ;
- простой пример;
- важный нюанс или предупреждение.

### Контент и источники
- Информация должна быть адаптирована под обычного пользователя.
- Желательно опираться на официальные правила и проверенные источники.
- Не стоит давать юридически точные заключения по конкретным спорным ситуациям.

### Техническая идея
Рекомендуемый стек для первого этапа:
- Python
- python-telegram-bot или aiogram
- SQLite или PostgreSQL
- JSON/Markdown для хранения вопросов и ответов

### Основные задачи первого этапа
- Сформировать структуру меню.
- Подготовить базу частых вопросов и ответов.
- Реализовать базовые сценарии общения.
- Проверить удобство интерфейса и понятность сообщений.
